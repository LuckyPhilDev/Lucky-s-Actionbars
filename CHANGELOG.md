## [0.5.5] - 2026-11-08

### Improved
- **Edit Mode marker** Lucky's Actionbars settings in Edit Mode are marked with a clearer icon, taken from the addon's minimap icon, that stays readable at text size.

### Fixed
- On WoW Forever, Backpack only no longer leaves the dividers between the hidden bag slots showing on the Bags bar.

## [0.5.4] - 2026-11-05

### Added
- **Controller layout** On WoW Forever, the controller bars' Edit Mode settings can move the side groups and shoulder icons apart or closer, and raise or lower every group and the shoulder icons.

## [0.5.3] - 2026-11-01

### Improved
- **Mouseover fade** Faded bars at rest check the mouse about 20 times a second instead of every frame, so they cost far less while you play.

## [0.5.2] - 2026-10-26

### Added
- **Wago Addons** Lucky's Actionbars is now published on Wago Addons too, so you can install and update it with the Wago app.

## [0.5.1] - 2026-10-23

### Fixed
- Keybinds on the action bars show the short form the default bars use, such as "a-D" for Alt-D, so they stay readable on smaller buttons instead of being cut off. (Thanks for the report Halliday)
- Default action bars hidden behind Lucky's Actionbars no longer throw "Secret values are only allowed during untainted execution" errors from their cooldowns.

## [0.5.0] - 2026-10-14

### Added
- **Masque on every bar** Action Bars 1 to 8 can be skinned with Masque too, each bar in its own group, the same as Action Bars 9 to 12.

### Improved
- **Proc glow** Spell procs on Action Bars 9 to 12 show Blizzard's own proc animation instead of the older marching ants.

### Fixed
- Paged bars no longer throw "Secret values are only allowed during untainted execution" errors in combat, or show stale icons and cooldowns after you release the modifier.
