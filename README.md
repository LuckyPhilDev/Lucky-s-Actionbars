# Lucky's Actionbars

Adds hold-to-page to the stock main action bar, no bar replacement needed.

## Features

- **Ctrl paging**: hold Ctrl and the main action bar shows its second page. Release and it returns to whatever it showed before, including stance, form and stealth pages.
- **Keybinds follow the page**: while Ctrl is held, your main action bar keys press the buttons on the second page. Any Ctrl key you have already bound to something else is left alone.
- **Works in combat**: paging runs through the game's secure state system.
- **Stays out of the way**: vehicles, override bars, possession and pet battles are never paged.

## Usage

Hold Ctrl and drag spells onto the main action bar to fill its second page. After that, hold Ctrl and press a bar key to cast from it.
